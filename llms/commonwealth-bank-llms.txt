# Commonwealth Bank (CommBank)

> Commonwealth Bank of Australia (CBA) is Australia's largest bank and a designated Consumer Data Right (CDR) Open Banking data holder. It exposes a PUBLIC Product Reference Data API and consumer-authorised CDR Banking endpoints (accounts, balances, transactions, direct debits, scheduled payments, payees, customer) conforming to the DSB Consumer Data Standards CDR Banking API v1.36.0, plus a partner-gated business API catalogue (Fast Payment/NPP, NameCheck, PayTo) and a merchant Payment Gateway.

## APIs (harvested OpenAPI/Swagger)
- [CDR Product Reference Data (public)](openapi/commonwealth-bank-cdr-products-openapi.json): listProducts, getProductDetail — unauthenticated, x-v header only
- [CDR Accounts](openapi/commonwealth-bank-cdr-accounts-openapi.json): listAccounts, getAccountDetail
- [CDR Balances](openapi/commonwealth-bank-cdr-balances-openapi.json): getBalances, listBalancesBulk, listBalancesSpecificAccounts
- [CDR Transactions](openapi/commonwealth-bank-cdr-transactions-openapi.json): getTransactions, getTransactionDetail
- [CDR Regular Payments](openapi/commonwealth-bank-cdr-regular-payments-openapi.json): direct debits + scheduled payments
- [CDR Payees](openapi/commonwealth-bank-cdr-payees-openapi.json): listPayees, getPayeeDetail
- [CDR Customer](openapi/commonwealth-bank-cdr-customer-openapi.json): getCustomer, getCustomerDetail
- [CDR Banking (DSB standard v1.36.0)](openapi/commonwealth-bank-cds-banking-openapi.json): full 16-endpoint shared standard
